I. ພາກປາລະໄນ

1. ຫຼັກການນຳໃຊ້ Ultrasonic Sensor ແມ່ນແນວໃດ?

ຕອບ: ກ. ສົ່ງຄື້ນ Ultrasonic ກະທົບວັດຖຸ

2. ຂາສັນຍານຂອງ Ultrasonic Sensor ມີຂາສັນຍານໃດແດ່?

ຕອບ: ງ. ຂໍ້ ກ ແລະ ຂ ຖືກ

3. ການຂຽນຄຳສັ່ງນຳໃຊ້ Ultrasonic Sensor ຈຳເປັນຕ້ອງໃຊ້ Library ບໍ?

ຕອບ: ງ. ບໍ່ຈຳເປັນຕ້ອງໃຊ້ Library

4. ຄວາມຈຳເປັນຂອງການນຳໃຊ້ Ultrasonic Sensor ປະກອບການເຮັດໂປຣເຈັກ?

ຕອບ: ກ. ກະແສໄຟຟ້າ

5. Temperature Sensor ໃຊ້ເຮັດຫຍັງ?

ຕອບ: ຂ. ໃຊ້ກວດສອບອຸນຫະພູມ

6. ການໃຊ້ງານ Temperature Sensor ສິ່ງທີ່ຄວນລະວັງແມ່ນຫຍັງ?

ຕອບ: ຄ. ແປໄຟ

7. ເປັນຫຍັງການນຳໃຊ້ Temperature Sensor ຈຶ່ງຕ້ອງໃຊ້ການສະແດງຜົນ?

ຕອບ: ກ. ໃຫ້ຜູ້ຮັກສາລະບົບຮູ້ການເຕືອນ

8. Temperature Sensor ມີການປະກາດນຳໃຊ້ Library ເຮັດແນວໃດ?

ຕອບ: ກ. ໃຊ້ຄຳສັ່ງນຳເຂົ້າ (#include)

9. PIR Sensor ແມ່ນອຸປະກອນຫຍັງ?

ຕອບ: ງ. ແມ່ນອຸປະກອນກວດຈັບການເຄື່ອນໄຫວ

10. ຮູບແບບ PIR Sensor ຈັດຢູ່ໃນຮູບແບບໃດຂອງ Sensor?

ຕອບ: ຂ. ແບບກວດສອບ

11. PIR Sensor ທີ່ພວກເຮົານຳໃຊ້ເປັນລັກສະນະໃດ?

ຕອບ: ຂ. ເປັນບອດຄວບຄຸມ

12. ຄຳສັ່ງທີ່ນຳໃຊ້ PIR Sensor ເປັນແນວໃດ?

ຕອບ: ຄ. ເປັນຟັງຊັນ

13. IR Sensor ເປັນອຸປະກອນແບບໃດ?

ຕອບ: ຂ. ຮັບສັນຍານ

14. ການນຳໃຊ້ IR Sensor ປະກອບໃນໂປຣເຈັກ ຈັດຢູ່ໃນການສັ່ງການແບບໃດ?

ຕອບ: ກ. ສັ່ງໃຫ້ປ້ອນຄ່າ

15. ເປັນຫຍັງ IR Sensor ຈຶ່ງຕ້ອງໃຊ້ຮ່ວມກັບ IRremote?

ຕອບ: ຂ. ຍ້ອນເປັນການຮັບຂໍ້ຄວາມ

16. ຈົ່ງໝາຍເອົາຄຳຕອບທີ່ຖືກຕ້ອງ CODE IR Sensor?

ຕອບ: ຄ. 0x0000FFFF

17. Photoresistor ເຮັດວຽກແນວໃດ?

ຕອບ: ກ. ເຮັດໜ້າທີ່ກວດສອບແສງ

18. Photoresistor ໃຊ້ຂາສັນຍານແບບໃດ?

ຕອບ: ງ. ຂາສັນຍານ analog

19. ການປະກາດຕົວແປ Photoresistor ທີ່ຖືກຕ້ອງແມ່ນຂໍ້ໃດ?

ຕອບ: ງ. int ldr = A0;

2. Temperature + LCD + LED

cpp 
#include <Adafruit_LiquidCrystal.h>
Adafruit_LiquidCrystal lcd(0);
int lm35 = A0;
#define led_gr 12
#define led_red 13

void setup() {
  lcd.begin(16, 2);
  lcd.print("Temperator");
  delay(500);
  Serial.begin(9600);
  pinMode(led_gr, OUTPUT);
  pinMode(led_red, OUTPUT);
  pinMode(lm35, INPUT);
}

3. Ultrasonic Sensor

cpp 
pinMode(ECHOPIN, INPUT);
int distance = pulseIn(ECHOPIN, HIGH);
distance = distance / 58;
Serial.print(distance);
